Kredensial Engine GitHub

Cara Menggunakan NexaBuilder

Siapkan Repository Mesin

Buat repository baru di GitHub kamu (misalnya bernama mesin-apk). Pastikan tipenya Public.

Pasang Skrip Anti-Gagal

Di dalam repo tersebut, buat file baru dengan struktur folder:
.github/workflows/build.yml
Paste skrip Ultimate Engine yang telah kami sediakan ke dalam file tersebut, lalu klik Commit.

Buat Token Akses Rahasia

Buka menu Settings di akun GitHub > Developer settings > Personal access tokens > Tokens (classic). Centang perizinan repo dan workflow. Simpan kode token tersebut (berawalan ghp_...).

Hubungkan & Eksekusi

Buka tab Konfigurasi Server di aplikasi ini, masukkan data GitHub kamu. Kembali ke tab Workspace, isi nama dan URL target, lalu klik Mulai Build!
